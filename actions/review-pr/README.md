# agents-maker PR Review Action

Run `reviewer_agent` on any pull request diff and post a structured, severity-rated review comment automatically.

Every PR gets a `refinement_report`:

```
## Refinement Report

**Verdict**: minor_revisions_needed

**Summary**: 0 critical, 1 high, 2 medium, 3 low

### Findings

| Severity | Area | Issue | Recommendation |
|---|---|---|---|
| high | auth/middleware.py | Rate limit key uses IP only — X-Forwarded-For spoofable | Validate against a trusted proxy allowlist before trusting header |
| medium | tests/test_rate_limit.py | No test for concurrent requests | Add asyncio.gather() stress test with 20 simultaneous requests |
| low | rate_limit.py | Magic number 60 (window seconds) | Extract to RATE_LIMIT_WINDOW_SECONDS constant |

### Positive Findings
- Pipeline pattern for Redis operations is correct and avoids N+1 round trips
- Fail-open exception handler prevents auth outage on Redis downtime

---
*Generated by agents-maker · reviewer_agent*
```

---

## Setup (4 lines)

**1. Store your API key as a repository secret**

Go to Settings → Secrets and variables → Actions → New repository secret:
- Name: `ANTHROPIC_API_KEY`
- Value: your Anthropic API key

**2. Create `.github/workflows/review.yml` in your repo**

```yaml
name: PR Review

on:
  pull_request:
    types: [opened, synchronize, reopened]

jobs:
  review:
    runs-on: ubuntu-latest
    permissions:
      pull-requests: write   # required to post comments
      contents: read
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - uses: Prateek-N/Multi-Agent-Stack/actions/review-pr@main
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
```

That's it. Every new PR gets a structured AI review comment.

## Inputs

| Input | Required | Default | Description |
|---|---|---|---|
| `anthropic_api_key` | Yes | — | Anthropic API key |
| `model` | No | `claude-haiku-4-5-20251001` | Claude model to use |
| `max_files` | No | `20` | Max changed files to include in review |
| `fail_on_critical` | No | `true` | Exit 1 if critical findings found |
| `pr_number` | No | auto | Override PR number (useful for manual triggers) |

## Model recommendations

| Model | Speed | Cost | Best for |
|---|---|---|---|
| `claude-haiku-4-5-20251001` | Fast (~10s) | Low | Most PRs — default |
| `claude-sonnet-4-6` | Medium (~25s) | Medium | Complex architecture changes |
| `claude-opus-4-7` | Slow (~60s) | High | Security-critical or large refactors |

## Using your agents-maker reviewer spec

If your repo includes `agents-maker/` (the full kit), the action automatically loads
`agents-maker/agents/reviewer_agent.md` as the reviewer spec — giving you the full
domain-aware, severity-calibrated review contract. If the spec is not found,
a minimal fallback spec is used that still produces a valid `refinement_report`.

---

## Customizing the review focus

Override `fail_on_critical` per workflow:

```yaml
- uses: Prateek-N/Multi-Agent-Stack/actions/review-pr@main
  with:
    anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
    model: claude-sonnet-4-6
    fail_on_critical: 'false'   # review without blocking merge
    max_files: '30'
```
